# Open Museum CMS v0.2.0-alpha

This alpha revises the generic foundation around two priorities: **broader collections applicability** and **easier administration for non-technical museums**.

## Highlights

- optional Analysis Profiles replace collection-type-specific expansion;
- profiles for art, sculpture, furniture, textiles/costume, tools, agriculture/rural life, Indigenous cultural context, historic photography, jewellery/adornment, arms/armour, archaeology, ceramics/glass, and Natural History;
- Analysis Profile field builder in the Administrator Setup interface;
- larger curated starter vocabulary for Classification, Object Type, Materials, Techniques, periods, and analysis options;
- core Culture/Community, Period, School/Style, and Credit Line fields;
- stronger faceted search across core and analytical metadata;
- The Met Open Access vocabulary-extraction helper;
- documented British Museum / Met / CDWA source and licensing approach;
- revised starter workbook and non-technical setup guide.

## Important vocabulary note

The starter vocabulary is intentionally curated rather than exhaustive. The Met's Open Access dataset may be used to generate additional candidates under its CC0 release. British Museum catalogue structure informed the design, but British Museum website content is not wholesale scraped or redistributed.

## Alpha warning

Back up real catalogue data and test new releases against a copy before updating a production deployment.
