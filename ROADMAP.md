# Roadmap

## Before 1.0

- Formal schema-version migration runner rather than one idempotent setup function.
- Easier bulk import/export mapping for legacy spreadsheets.
- Optional vocabulary-pack importer/exporter from the Setup screen.
- Additional condition/conservation support.
- Optional loans module.
- More granular rights and restrictions controls.
- Improved performance for larger catalogues.
- Accessibility audit and keyboard-navigation review.
- Documentation for migration from common spreadsheet catalogues.
- Installer/checklist that verifies Apps Script services and permissions automatically.

## Longer term

- Optional public-collections portal separate from the internal CMS.
- Optional Darwin Core export where Natural History data justify it.
- Optional IIIF integration for high-resolution media.
- More robust API/data export layer.
- Community-contributed analysis-profile and vocabulary packs.

Roadmap items are proposals, not guarantees.
