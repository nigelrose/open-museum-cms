# Starter files

`Open_Museum_CMS_Starter.xlsx` is a blank, styled catalogue workbook matching the current alpha schema.

1. Upload it to Google Drive and open/convert it in Google Sheets.
2. Add the Apps Script files from `src/`.
3. Run `setupOpenMuseumCms()`.
4. Create a Test deployment.
5. Use the CMS **Setup** page for institution name, branding, users, storage, vocabulary, and analysis-profile configuration.

You may also start from a completely blank Google Sheet; setup creates missing tables.

`Controlled_Vocabularies.csv` is provided for review/reference. The live CMS uses the `Lists` sheet and the setup seed logic in `Code.gs`.
